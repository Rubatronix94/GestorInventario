# 📦 GestorInventario

Aplicación web desarrollada con **ASP.NET Core MVC** para la gestión básica de inventario de productos.

Este proyecto forma parte de mi **portfolio como desarrollador .NET** y demuestra la implementación de operaciones CRUD, autenticación de usuarios y persistencia de datos utilizando Entity Framework Core.

---

# 🚀 Características

- Gestión de productos (CRUD)
- Autenticación de usuarios
- Persistencia de datos con Entity Framework Core
- Arquitectura basada en MVC
- Validación de modelos con DataAnnotations
- Interfaz web con Razor Views y Bootstrap

---

# 🧰 Tecnologías utilizadas

- **ASP.NET Core MVC**
- **C#**
- **Entity Framework Core**
- **SQL Server / LocalDB**
- **Bootstrap**
- **Git & GitHub**

---
